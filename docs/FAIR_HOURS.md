# Horários das feiras do DF — base do Feiraê

## Regra de uso no aplicativo

O horário da feira não deve ser inventado nem reutilizado de outra feira.

A Lei nº 6.956/2021 atribui à Administração Regional a definição de dias e horários de funcionamento conforme o regimento interno. Em 2026, a Portaria SEGOV nº 54 autorizou as feiras permanentes do DF a funcionar **até 22h**, mas deixou a abertura/fechamento a cargo de cada Administração Regional/regimento.

Portanto:

- “até 22h” é **limite regulatório**, não o horário de todas as feiras;
- cada feira deve possuir sua própria agenda;
- horários especiais/feriados devem ser tratados como exceções;
- fonte antiga deve ser marcada para revalidação;
- sem fonte específica confiável, mostrar “Horário a confirmar”.

## Status das fontes

- **CONFIRMADO ATUAL** — ato oficial recente localizado.
- **OFICIAL / REVALIDAR** — ato/fonte oficial específica localizada, porém antiga e sujeita a alteração posterior.
- **PENDENTE** — não foi localizada nesta pesquisa uma norma pública específica atual suficiente para alimentar o app.

## Próxima etapa de dados

Para as linhas PENDENTES, a base real deve ser confirmada com:

- SINJ/DODF;
- Administração Regional competente;
- regimento interno vigente;
- eventual ordem de serviço posterior.

No banco futuro, cada agenda deve guardar:

- `source_url`;
- `source_type`;
- `verified_at`;
- `valid_from`;
- `valid_until` opcional;
- agenda semanal;
- exceções/feriados;
- status de verificação.

Nenhuma tela deve transformar “PENDENTE” em horário fictício.
